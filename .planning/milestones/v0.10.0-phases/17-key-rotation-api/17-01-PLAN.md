**2. Add `rotate_key()` to `UnifiedCache` in `src/cacheness/core.py`** (per D-01, D-02, D-04, D-05, D-06, D-07, D-09, D-12):

Add the method after `_sign_current_namespace()` (~L395). Implementation:

```python
def rotate_key(self, new_key_file: str | Path) -> "RotationResult":
```

Logic:
- Import `RotationResult` from `.interfaces` and `create_cache_signer` from `.security` (at top of method or module level).
- Validate: if `self.signer is None`, raise `CacheSecurityError("Entry signing is not enabled — cannot rotate key")`.
- Validate `new_key_file` exists, is a file, and has 32 bytes — raise `CacheSecurityError` with clear message on failure.
- Acquire `self._lock` (per D-06 — hold lock for entire operation).
- Create new signer via `create_cache_signer(cache_dir=self.cache_dir, key_file=str(Path(new_key_file).name), use_in_memory_key=False, key_fallback_policy=self.config.security.key_fallback_policy, namespace_id=self.namespace, use_hkdf_derivation=self.config.security.use_hkdf_derivation)`. Note: The new key file must be at the expected path in cache_dir. Copy the new key file into `self.cache_dir / self.config.security.signing_key_file` before creating signer, overwriting the old key. This way `create_cache_signer` loads it.  
  Actually, simpler: read the 32-byte key from `new_key_file`, write it to `self.cache_dir / self.config.security.signing_key_file`, then call `create_cache_signer()` which will load it.
- Initialize `RotationResult`.
- Iterate entries via `self.metadata_backend.iter_entry_summaries()`.
- Set `result.total` to length of entries list.
- For each entry (best-effort per D-05):
  - Wrap in try/except. On failure: `result.failed += 1`, append to `result.failures`, continue.
  - `cache_key = entry["cache_key"]`
  - `full_entry = self.metadata_backend.get_entry(cache_key)` — if None, skip (`result.skipped += 1`).
  - `metadata = full_entry.get("metadata", {})`
  - `signable = self._extract_signable_fields(cache_key, full_entry, metadata)`
  - `new_sig = new_signer.sign_entry(signable)` — always produces v3 (HKDF enabled).
  - `metadata["entry_signature"] = new_sig`
  - `full_entry["metadata"] = metadata`
  - `self.metadata_backend.put_entry(cache_key, full_entry)`
  - `result.re_signed += 1`
- Re-sign namespace (per D-12):
  - `ns_info = self.metadata_backend.get_namespace(self.namespace)`
  - If ns_info is not None: build ns_data dict, call `new_signer.sign_namespace(ns_data)`, call `self.metadata_backend.set_namespace_signature(ns_info.namespace_id, new_sig)`.
- Replace `self.signer = new_signer`.
- Return result.

**Important:** The lock is held via `with self._lock:` for the entire body. Use the existing re-sign pattern from update operations (~L2391-2427) as reference for _extract_signable_fields → sign_entry → put_entry flow.

**Do NOT add:** Crash detection on init, rotation_incomplete flags, or auto-recovery logic. The existing version routing (v1/v2→master_key, v3→derived_key) already handles mixed state after crashes (per D-07, D-08).

**Add `rotate_key()` to `BlobStore`** (per D-10, D-11):

Add the method after the existing `_init_signer()` method (~L260). Implementation:

```python
def rotate_key(self, new_key_file: str | Path) -> "RotationResult":
```

Logic mirrors UnifiedCache but adapted for BlobStore's signing pattern:
- Import `RotationResult` from `..interfaces` and `create_cache_signer` from `..security`.
- Validate: if `self.signer is None`, raise `CacheSecurityError("Entry signing is not enabled — cannot rotate key")`.
- Validate `new_key_file` exists, is a file, 32 bytes.
- Acquire `self._lock`.
- Read 32-byte key from new_key_file, write to `self.cache_dir / "cache_signing_key.bin"` (or whatever self.signer.key_file_path.name is), overwriting old key.
- Create new signer via `create_cache_signer(cache_dir=self.cache_dir, key_file=self.signer.key_file_path.name, use_in_memory_key=False, key_fallback_policy=self.signer.key_fallback_policy, namespace_id=self._namespace, use_hkdf_derivation=self.signer.use_hkdf_derivation)`.
- Initialize `RotationResult`.
- Iterate entries via `self.backend.iter_entry_summaries()`.
- For each entry (best-effort):
  - `cache_key = entry["cache_key"]`
  - `full_entry = self.backend.get_entry(cache_key)` — skip if None.
  - BlobStore's signing pattern: flatten entry + nested metadata for signing.
    ```python
    nested_meta = full_entry.get("metadata", {})
    signable = {**full_entry, **nested_meta, "cache_key": cache_key}
    new_sig = new_signer.sign_entry(signable)
    ```
  - Store signature in both top-level and nested metadata (matching put() pattern):
    ```python
    full_entry["entry_signature"] = new_sig
    nested_meta["entry_signature"] = new_sig
    full_entry["metadata"] = nested_meta
    ```
  - `self.backend.put_entry(cache_key, full_entry)`
  - `result.re_signed += 1`
- BlobStore does NOT manage namespace registry — skip namespace re-signing (that's UnifiedCache's responsibility).
- Replace `self.signer = new_signer`.
- Return result.

**Use the same validation and error handling pattern as Task 1.** Key difference: BlobStore uses `self.backend` (not `self.metadata_backend`) and the flatten-for-signing pattern from its `put()` method.
