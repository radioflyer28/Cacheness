<action>
Add "Encryption at Rest" section to `docs/SECURITY.md` after the "Key Rotation" section:

1. **Overview:** AES-256-GCM authenticated encryption, optional, disabled by default
2. **Configuration:** Show SecurityConfig fields:
   - `enable_content_encryption: bool = False`
   - `encryption_key_file: str = "cache_signing_key.bin"`
3. **Usage example:**
   ```python
   from cacheness.core import UnifiedCache
   cache = UnifiedCache(
       cache_dir="./secure_cache",
       security={"enable_content_encryption": True, "signing_key_file": "my_key.bin"}
   )
   cache.put("sensitive data", prefix="secrets", description="api_token")
   data = cache.get(prefix="secrets", description="api_token")  # transparently decrypted
   ```
4. **How it works:** Encrypt-then-sign, per-namespace key derivation via HKDF, random 12-byte IV per blob
5. **Migration:** Unencrypted entries remain readable when encryption is enabled. No batch re-encryption needed.
6. **Dependencies:** Requires `cryptography>=41.0.0` — install via `pip install cacheness[encryption]`
7. **Performance note:** AES-GCM adds modest overhead; negligible for blobs >1KB
</action>
