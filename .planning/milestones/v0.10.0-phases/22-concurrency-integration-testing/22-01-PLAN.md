    **Class `TestConcurrentRotateKey`:**

    1. `test_rotate_key_during_concurrent_puts(self, signing_cache)`:
       - Pre-populate 20 entries: `cache.put(f"data-{i}", key=f"entry-{i}")` for i in 0..19
       - Create a new 32-byte key file in the temp dir
       - Launch 8 writer threads doing `cache.put(f"new-{i}-{j}", key=f"new-{i}-{j}")` in a loop (5 puts each)
       - Simultaneously launch 1 thread calling `cache.rotate_key(new_key_path)`
       - Join all threads with timeout=60
       - Assert no exceptions in any thread (collect errors in a list)
       - Assert `cache.get("entry-0")` returns valid data (not None, not corrupt)
       - Assert at least 20 entries exist via `len(cache.list()) >= 20`

    2. `test_rotate_key_during_concurrent_gets(self, signing_cache)`:
       - Pre-populate 50 entries
       - Launch 8 reader threads each doing `cache.get(f"entry-{i}")` for random i in 0..49, 10 reads each
       - Simultaneously launch 1 thread calling `cache.rotate_key(new_key_path)`
       - Join all threads with timeout=60
       - Assert no exceptions (reads during rotation may return None for entries being re-signed, which is acceptable, but must not raise)
       - After rotation completes, assert `cache.get("entry-0")` is not None

    3. `test_rotate_key_result_consistent(self, signing_cache)`:
       - Pre-populate 30 entries
       - Call `rotate_key()` (single-threaded)
       - Assert `result.re_signed + result.failed + result.skipped == 30`
       - Assert `result.re_signed >= 1` (at least some succeeded)

    **Class `TestConcurrentEncryptedAccess`:**

    4. `test_concurrent_encrypted_put_get(self, encrypted_cache)`:
       - Launch 8 writer threads, each putting 10 entries: `cache.put(f"data-{tid}-{i}", key=f"enc-{tid}-{i}")`
       - Wait for all writers to complete
       - Launch 8 reader threads, each reading all 10 entries they wrote
       - Assert no errors in any thread
       - Assert all 80 entries present: `len(cache.list()) == 80`
       - Assert each entry round-trips correctly: `cache.get(f"enc-{tid}-{i}") == f"data-{tid}-{i}"`

    5. `test_concurrent_encrypted_put_same_key(self, encrypted_cache)`:
       - Launch 8 threads all writing to key="shared-enc" with different data
       - Assert no exceptions
       - Assert `cache.get("shared-enc")` returns one of the written values (last-writer-wins, but no corruption)
