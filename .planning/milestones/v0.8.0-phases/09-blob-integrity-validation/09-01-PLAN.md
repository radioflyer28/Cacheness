<objective>
Add signature verification to verify_integrity() so bulk audit catches both corruption AND tampering.

Purpose: Currently verify_integrity() only checks hash/size mismatches. Adding HMAC signature verification provides end-to-end validation — confirming that blob content matches stored hash AND that metadata hasn't been tampered with.

Output: Updated verify_integrity() with verify_signatures parameter, extended IntegrityReport, new tests.
</objective>
