## Trust Boundaries

| Boundary | Description |
|---|---|
| authenticated authority → payload delete | Destructive action requires exact current non-ownership and contained locator proof. |
| concurrent callers → per-key/authority CAS | Local ordering cannot replace backend correctness or create global serialization. |
| close caller → owned resources | Caller injection and internal ownership determine what may be released. |
