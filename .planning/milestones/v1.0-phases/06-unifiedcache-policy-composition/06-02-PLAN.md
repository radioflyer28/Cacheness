## Trust Boundaries

| Boundary | Description |
|---|---|
| Catalog page -> policy selection | Only authenticated canonical facts may drive removal decisions. |
| Policy selection -> lifecycle delete | A stale selected generation must not authorize deletion of a replacement. |
| Public invalidation scope -> catalog query | Caller scope must be validated and bounded before authority access. |

| T-06-06 | Denial of service | global/predicate invalidation | high | mitigate | Enforce page and total-work caps and return opaque continuation state. |
| T-06-07 | Elevation of privilege | arbitrary predicate | high | mitigate | Restrict predicates to validated indexed catalog fields and reject unsupported scope before I/O. |
