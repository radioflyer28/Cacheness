<objective>
Prove the thinnest complete cache-policy path: an explicitly composed memory cache stores None, observes it once through BlobStore, returns HIT with value None, and records that outcome in the shared immutable statistics model.

Purpose: Establish the one presence/outcome seam that every later policy and decorator path consumes, without reopening storage lifecycle sequencing.
Output: Frozen policy result models, one-read lookup orchestration, and executable lookup/statistics contracts.
</objective>
