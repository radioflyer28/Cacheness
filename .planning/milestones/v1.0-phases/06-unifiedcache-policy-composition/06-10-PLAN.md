<interfaces>

BlobStore.query_catalog accepts a CatalogQuery plus schema, cursor, limit, and work_cap and returns CatalogPage with typed CatalogEntry values and authority-owned continuation. UnifiedCache.put returns CachePutResult; optional cache_key_params metadata is configured only by CacheConfig(metadata=CacheMetadataConfig(store_cache_key_params=...)) and can be inspected from the selected BlobStore using the committed receipt key.
</interfaces>
