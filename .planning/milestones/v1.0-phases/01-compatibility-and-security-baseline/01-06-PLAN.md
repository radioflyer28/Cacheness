<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller adapter/gap detector to SqlCache | Caller-controlled code can fail, return empty data, or propose incomplete ranges. |
| Missing-range loop to transaction | Per-range mutation can commit a subset before a later failure. |
| Internal fallback to observability | Bulk-to-row recovery is safe only if equivalent and visible; double failure must not disappear. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-20 | Tampering / Integrity | SqlCache missing-range fetch | high | mitigate | Stage all strict results, collect every failure/empty response, rollback before storage, and raise typed completeness error. |
| T-01-21 | Repudiation | best-effort partial result | high | mitigate | Opt-in distinct result type with `is_partial`, ordered failure records, and one structured log per range. |
| T-01-22 | Tampering | custom gap detector fallback | medium | mitigate | Raise typed cause-preserving error by default; fallback only under explicit best effort and report its use. |
| T-01-23 | Repudiation / Integrity | bulk-to-row upsert fallback | medium | mitigate | Structured warning on equivalent fallback; typed rollback/error if both paths fail. |
</threat_model>
