## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Caller filter key to JSON/SQL expression | Field names previously reached SQL text while only values were bound. |
| Filter mapping to database session | Partial validation could execute earlier predicates before discovering a hostile later field. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-17 | Tampering / Information Disclosure | query_meta field path | high | mitigate | Fixed segment grammar, bounded depth/length, whole-set validation, and bound JSON path/value parameters. |
| T-01-18 | Denial of Service | malformed/deep query fields | medium | mitigate | Reject empty, overlength, overdepth, control, bracket, quote, operator, and separator syntax before session creation. |
| T-01-19 | Repudiation | generic query exception handling | medium | mitigate | Typed error with stable reason and invalid-field context bypasses failure-to-None translation. |
</threat_model>
