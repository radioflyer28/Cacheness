<interfaces>
Preserve and exercise these existing contracts directly:

- `SqliteLifecycleAuthority.for_root(root, lifecycle_limits=..., lifecycle_topology=...)` validates both injected configuration objects before creating the root.
- `SqliteLifecycleAuthority._deadline(deadline)` accepts `None` or a numeric monotonic timestamp but rejects booleans and non-numeric values with `TypeError("deadline must be a monotonic timestamp")`.
- `SqliteLifecycleAuthority._remaining_for_stage(...)` raises `CacheBlobLifecycleTimeoutError("Lifecycle authority busy deadline expired")` with canonical operation, stage, elapsed/remaining, timeout, path, and retryable context.
- `SqliteLifecycleAuthority._set_busy_timeout(connection, milliseconds)` accepts only a non-negative exact integer and raises `ValueError("SQLite busy timeout must be a non-negative integer")` before executing invalid input.
- `SqliteLifecycleAuthority._apply_stage_busy_timeout(...)` translates a real `sqlite3.Error` from the connection into the established typed backend error while preserving its cause.
- `SqliteLifecycleAuthority.initialize()` creates or validates the current authority; reopening malformed `store_identity` rows or a missing required schema table fails with `CacheBlobMigrationRequiredError` and does not repair the database.
- `tools/verify_phase8_coverage.py::parse_coverage_report()` returns repository and fixed critical-scope raw counts; ordinary `verify` is read-only and the baseline remains immutable.
</interfaces>
