<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| custom handler -> private stage | User code chooses output paths and file shape. |
| authority locator -> obstore | Persisted locators are untrusted until contained and normalized. |
| obstore stream -> handler snapshot | Remote/local bytes must be bounded, complete, and canonically verified before deserialization. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07.1-03-01 | Elevation | locator/path containment | high | mitigate | Reject hostile locator forms before every store call and retain guarded private roots. |
| T-07.1-03-02 | Tampering | staged-file TOCTOU | high | mitigate | Publish only from the retained validated descriptor/inode and reject symlinks/non-regular files. |
| T-07.1-03-03 | Denial of Service | staged/read payload size | medium | mitigate | Enforce upload/download byte caps and count streamed bytes before handler execution. |
| T-07.1-03-04 | Repudiation | SDK error mapping | high | mitigate | Normalize only typed collision/absence and preserve causes for other failures. |
| T-07.1-03-05 | Tampering | handler deserialization order | high | mitigate | Complete private snapshot and canonical SHA-256/size verification before `handler.get`. |
</threat_model>
