# Phase 07.1 Plan 03: Obstore Local and Memory Generation I/O Summary

**One bounded obstore participant now carries built-in NPZ and store-local MCAP payloads through LocalStore and MemoryStore while retaining private path-handler staging, exact immutable recovery, and AuthorityLifecycleEngine as the only lifecycle coordinator.**

## Accomplishments

- Added `ObstoreGenerationIO`, a single five-method LocalStore/MemoryStore payload participant that passes retained guarded descriptors to conditional create and supplies private bounded snapshots.
- Preserved native NPZ and custom MCAP-style path handlers: handlers see only suffix-preserving private paths, never obstore values or managed locators.
- Added deterministic contracts for exact immutable collision, accepted-response recovery, mismatch conflict, deletion/absence, hostile locator rejection, stage-artifact safety, and 128 MiB-default transfer limits.

## Decisions Made

- A response-lost conditional create is accepted only after exact `head()` and a bounded exact-object SHA-256/size match; the lifecycle engine still performs its normal independent verification and promotion.
- `AlreadyExistsError` and create-scoped `PreconditionError` normalize to immutable-generation collisions. Known absence variants normalize only where the operation proves absence; other obstore failures preserve their causes in typed backend errors.
- No lock, listing-driven recovery, timing policy, or parallel lifecycle coordinator was introduced. `AuthorityLifecycleEngine` remains the sole authority for prepare, verify, promote, and cleanup debt.
