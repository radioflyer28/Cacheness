<interfaces>
Existing authority values are frozen and bounded. SQLite has `SQLITE_APPLICATION_ID`, `SQLITE_USER_VERSION`, a singleton authority revision, `_read_connection()`, `_transaction()`, and key-ordered canonical rows. PostgreSQL has `POSTGRESQL_AUTHORITY_SCHEMA_VERSION`, `POSTGRESQL_AUTHORITY_CAPABILITY`, `_read_only()`, `_transaction()`, and typed SQLSTATE mapping. Do not route administrative inventory through `catalog_page()` because that user query surface intentionally filters by catalog schema.
</interfaces>
