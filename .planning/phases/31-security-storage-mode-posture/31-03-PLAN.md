<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| key file to signer/encryptor | Key-file contents determine whether existing entries can be verified and decrypted. |
| rotation pass to stored entries | Rotation mutates signatures, encryption IVs, and blob ciphertext. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-05 | Denial of Service | `rotate_key()` active key replacement | mitigate | Stage `<keyfile>.new` and replace the active key only after all entries succeed per D-16 and D-20. |
| T-31-06 | Tampering | local encrypted blob re-encryption | mitigate | Write to `.rotating` and `os.replace` rather than in-place truncating writes per D-19. |
| T-31-SC | Tampering | package supply chain | accept | No package-manager installs are planned. |
</threat_model>
