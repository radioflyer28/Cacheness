<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Metadata locator/physical name to handler | Ordinary handler Path I/O can follow a retarget after lexical validation. |
| Private handler stage to managed publication | A handler result must be confined and copied/published through guarded operations. |
| Storage exception to cache policy | Broad catches can turn security failures into misses and delete evidence. |
| Multi-entry list/clear to mutation | One hostile record must not cause partial mutation of earlier safe records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering / Information Disclosure | high-level handler I/O | high | mitigate | Private stage/snapshot contract; ManagedFileOps is the sole managed byte boundary; API-level static/barrier/Unix stress tests. |
| T-01-06 | Repudiation | UnifiedCache broad exception handling | high | mitigate | Re-raise CacheUnsafePathError before cleanup/miss accounting and assert counters/metadata remain unchanged. |
| T-01-07 | Tampering / Denial of Service | BlobStore list/clear | high | mitigate | Preflight the complete entry set and reject with zero mutation before existing safe behavior. |
| T-01-12 | Elevation of Privilege / TOCTOU | locator retarget or pre-verification deserialization during native handler access | high | mitigate | Open/copy the managed locator once, retain a context-owned private snapshot through digest and current/legacy signature verification, and invoke the handler only afterward on that same snapshot; deletion policy cannot bypass verification. |
| T-01-37 | Tampering | caller-authored prefix | high | mitigate | Length-framed domain-separated hashing before path construction; preserve authored metadata only; hostile-prefix outside-sentinel tests. |
</threat_model>
