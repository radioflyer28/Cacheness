<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Legacy header bytes to shape/dtype | Metadata-controlled framing can execute code or exhaust resources if parsed broadly. |
| Declared format to reader dispatch | A malformed artifact must not trigger guessing of a more permissive sidecar. |
| Object-dtype array to executable serializer | NumPy object arrays require pickle semantics and cross the trusted-payload boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-13 | Elevation of Privilege / Denial of Service | legacy array tuple metadata | high | mitigate | Fixed bounded grammar, framing limits, checked arithmetic, non-object dtype, decompression and exact byte-agreement tests. |
| T-01-14 | Elevation of Privilege | ordinary NPZ loading | high | mitigate | Native NPZ reads keep pickle disabled; object dtype cannot reach ArrayHandler's ordinary reader. |
| T-01-15 | Tampering | declared-format dispatch | high | mitigate | One recorded format selects one reader; malformed/unsafe artifacts raise typed errors and never sidecar-fallback. |
| T-01-16 | Elevation of Privilege | explicit ObjectHandler routing | high | mitigate | Require explicit configuration plus Plan 03's same-snapshot digest/signature/unsigned verification before ObjectHandler; test that evidence-retention policy never permits deserialization after failed authenticity. |
</threat_model>
