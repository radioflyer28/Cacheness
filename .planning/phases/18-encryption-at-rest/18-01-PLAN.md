# Plan 18-01: Core Encryption Module + BlobStore Integration

## Goal
Implement AES-256-GCM encryption at rest — create the encryption module, extend SecurityConfig, wire into BlobStore put/get paths, and extend rotate_key() for re-encryption.

## Tasks

<task id="1" title="Encryption module + config extensions">

<read_first>
- src/cacheness/security.py (HKDF function `_hkdf_sha256`, CacheEntrySigner pattern)
- src/cacheness/config.py (SecurityConfig dataclass, ~L389-440)
- src/cacheness/interfaces.py (RotationResult dataclass)
- pyproject.toml (dependencies section, optional-dependencies)
</read_first>

<action>
1. **Add optional dependency** in `pyproject.toml`:
   - Add `encryption = ["cryptography>=41.0.0"]` to `[project.optional-dependencies]`

2. **Extend SecurityConfig** in `src/cacheness/config.py`:
   - Add field: `enable_content_encryption: bool = False`
   - Add field: `encryption_key_file: str = "cache_signing_key.bin"` (reuses signing key by default)
   - In `__post_init__`, if `enable_content_encryption` is True, check that `cryptography` is importable. If not, raise `CacheConfigurationError("Install cacheness[encryption] for AES-GCM encryption support: pip install cacheness[encryption]")`
   - Add to debug log line: `encryption={self.enable_content_encryption}`

3. **Create `src/cacheness/encryption.py`** with:
   - Import: `from .security import _hkdf_sha256`
   - Lazy import of `cryptography.hazmat.primitives.ciphers.aead.AESGCM` — availability flag `CRYPTOGRAPHY_AVAILABLE`
   - Function `derive_encryption_key(master_key: bytes, namespace_id: str) -> bytes`:
     - Returns `_hkdf_sha256(master_key, info=b"cacheness-aes-gcm-v1:" + namespace_id.encode())`
   - Function `encrypt_blob(data: bytes, key: bytes) -> tuple[bytes, bytes, bytes]`:
     - Generates 12-byte random IV via `os.urandom(12)`
     - Creates `AESGCM(key)` instance
     - Encrypts: `ciphertext = aesgcm.encrypt(iv, data, None)`
     - Note: AES-GCM appends 16-byte tag to ciphertext
     - Returns `(ciphertext, iv, b"aes-256-gcm")`
   - Function `decrypt_blob(ciphertext: bytes, key: bytes, iv: bytes) -> bytes`:
     - Creates `AESGCM(key)` instance
     - Decrypts: `plaintext = aesgcm.decrypt(iv, ciphertext, None)`
     - Returns `plaintext`
     - On `InvalidTag` exception: raise `CacheIntegrityError("Decryption failed — ciphertext has been tampered with or wrong key")`

4. **Extend RotationResult** in `src/cacheness/interfaces.py`:
   - Add field: `re_encrypted: int = 0`
</action>

<task id="2" title="Wire encryption into BlobStore put/get + extend rotate_key">

<read_first>
- src/cacheness/encryption.py (just created in Task 1)
- src/cacheness/storage/blob_store.py (put() ~L354-446, get() ~L448-530, rotate_key(), _init_signer())
- src/cacheness/core.py (rotate_key() method, _init_blob_store(), __init__)
- src/cacheness/config.py (SecurityConfig with new encryption fields)
</read_first>

<action>
1. **Add encryption initialization to BlobStore.__init__()** or a new `_init_encryptor()`:
   - Read the security config from `self.config` (it's a `CacheConfig` which has `security: SecurityConfig`)
   - If `security.enable_content_encryption` is True:
     - Read master key from `security.encryption_key_file` (same key-reading logic as signer)
     - Derive encryption key via `derive_encryption_key(master_key, namespace_id)` where namespace_id comes from config
     - Store as `self._encryption_key: Optional[bytes] = derived_key`
   - If encryption not enabled: `self._encryption_key = None`

2. **Modify BlobStore.put()** — after handler writes compressed file, before blob_backend.write_blob_from_path():
   - If `self._encryption_key is not None`:
     - Read the compressed file bytes: `plaintext = handler_path.read_bytes()`
     - Call `ciphertext, iv, algo = encrypt_blob(plaintext, self._encryption_key)`
     - Overwrite the handler file with ciphertext: `handler_path.write_bytes(ciphertext)`
     - Update `result.file_size` to len(ciphertext)
     - After `file_hash` calculation (hash the ENCRYPTED bytes, not plaintext — integrity of what's on disk)
     - Add to `custom_metadata`: `encryption_algorithm = "aes-256-gcm"`, `encryption_iv = iv.hex()`, `encryption_nonce_bytes = len(iv)`
   - If encryption not enabled: no changes to existing flow

3. **Modify BlobStore.get()** — after blob_backend.exists() check, before handler.get():
   - Check `nested_meta.get("encryption_algorithm")`:
     - If present (entry was encrypted):
       - If `self._encryption_key is None`: log warning "Encrypted entry but no encryption key configured", return None
       - Read encrypted bytes from file: `ciphertext = actual_path.read_bytes()`
       - Get IV: `iv = bytes.fromhex(nested_meta["encryption_iv"])`
       - Decrypt: `plaintext = decrypt_blob(ciphertext, self._encryption_key, iv)`
       - Write decrypted bytes to a temp file in same directory for handler to read
       - Use `tempfile.NamedTemporaryFile(dir=actual_path.parent, delete=False, suffix=actual_path.suffix)` 
       - Write `plaintext` to temp file, pass temp file path to handler.get()
       - Clean up temp file after handler.get() returns (in a finally block)
     - If absent: read as-is (unencrypted entry, no changes)

4. **Extend BlobStore.rotate_key()** — after re-signing, also re-encrypt:
   - If `self._encryption_key is not None` (new key has encryption enabled):
     - For each entry being rotated:
       - Check if entry has `encryption_algorithm` in metadata
       - If encrypted: decrypt with OLD encryption key, re-encrypt with NEW encryption key
       - Update metadata `encryption_iv` with new IV
       - Increment `result.re_encrypted`
     - Derive new encryption key from new master key: `new_enc_key = derive_encryption_key(new_key_bytes, namespace_id)`
     - Replace `self._encryption_key = new_enc_key`

5. **Wire encryption config in UnifiedCache**:
   - In `_init_blob_store()` or `__init__()`: pass security config to BlobStore so it can init encryption
   - Extend `UnifiedCache.rotate_key()`: after re-signing entries, if encryption is enabled, re-encrypt blobs (delegate to blob_store's rotate_key or handle inline)
</action>

<acceptance_criteria>
- BlobStore.put() encrypts blob content when `enable_content_encryption=True`
- BlobStore.get() decrypts blob content transparently when metadata contains `encryption_algorithm`
- BlobStore.get() returns None with warning when encrypted entry encountered but no encryption key configured
- BlobStore.get() reads unencrypted entries normally even when encryption is enabled (migration path — SC-5)
- Encrypted entry metadata contains `encryption_algorithm`, `encryption_iv` keys
- BlobStore.rotate_key() re-encrypts encrypted entries and increments `RotationResult.re_encrypted`
- `file_hash` in metadata is hash of ENCRYPTED bytes (what's on disk)
- Temp file cleanup happens in finally block during decryption read path
- No changes to handler interface — handlers are encryption-unaware
</acceptance_criteria>

</task>
