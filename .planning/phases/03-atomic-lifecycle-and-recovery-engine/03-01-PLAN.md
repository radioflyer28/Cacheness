## ASVS L1 Control Mapping

## Trust Boundaries

| Boundary | Description |
|---|---|
| handler private stage -> managed generation | Trusted payload bytes cross into persistent storage only after serialization completes and evidence exists. |
| repository/operation bytes -> lifecycle engine | Persisted control records are untrusted until bounded parsing, authentication, and provenance validation. |
| exact CAS result -> cleanup | Acknowledgement uncertainty must not authorize rollback or cross-generation deletion. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Tampering / Denial of Service | immutable generation publication | high | mitigate | Exclusive contained locator creation, candidate digest/size verification, and native-format tracer block overwrite or mixed state. |
| T-03-02 | Spoofing / Tampering | operation evidence | high | mitigate | Bounded versioned authenticated evidence binds store, key, operation, generation, and locators before cleanup. |
| T-03-03 | Tampering | authority acknowledgement | high | mitigate | Exact CAS plus reopen authentication classifies ambiguous acknowledgement and forbids speculative rollback. |
| T-03-04 | Information Disclosure | typed recovery context | low | accept | Context contains bounded identifiers/reasons only; payload and signing-key bytes are never logged. |
