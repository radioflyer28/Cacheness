# Phase 07.1 — Security

> Per-phase security contract for the obstore payload-participant cutover. This
> verifies the plan-authored controls without expanding the topology guarantees
> defined by ADR 0001.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Package registry/source → runtime | The pinned obstore native dependency implements built-in payload object mechanics. | Package code and dependency provenance |
| Handlers/locators → private staging and obstore | User-selected paths and persisted locators are untrusted until contained, bounded, and validated. | Serialized payload bytes and locators |
| Obstore/S3 → lifecycle engine | Object observations are transport evidence; metadata authority alone decides visibility. | Payload bytes, ETag, size, version, errors |
| Signed evidence → authority/read path | Transport evidence must be bounded, authenticated, and must not replace canonical verification. | HMAC-bound observations and canonical SHA-256/size |
| Authority transactions → object store | Database ACID does not extend across the external payload store. | Lifecycle state and immutable-generation effects |
| Public configuration/tests → qualification claims | Mocked behavior and transport corroboration must not be represented as live or canonical qualification. | Configuration, test evidence, operator guidance |
