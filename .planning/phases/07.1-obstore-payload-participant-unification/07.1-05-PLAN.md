<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| object metadata -> signed authority evidence | ETag/version/size originate outside the transaction and are untrusted until validated and bound. |
| authority evidence -> handler read | Transport corroboration must never bypass canonical payload verification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07.1-05-01 | Tampering | evidence transplant | high | mitigate | Domain-separated HMAC binds store/key identity, generation, locator, canonical SHA-256/size, and observed fields. |
| T-07.1-05-02 | Tampering | evidence parser | high | mitigate | Strict bounded exact-field decoding rejects unknown, duplicate, malformed, and unsupported inputs. |
| T-07.1-05-03 | Elevation | transport evidence as authority | high | mitigate | Only lifecycle `record_verification` persists evidence; adapter cannot promote or mutate authority. |
| T-07.1-05-04 | Tampering | deserialization-before-verification | high | mitigate | Retain manifest authentication and SHA-256/size verification before handler invocation. |
| T-07.1-05-05 | Denial of Service | evidence size | medium | mitigate | Bound raw encoding, strings, and numeric fields before HMAC or decode work. |
| T-07.1-05-06 | Tampering | stale metadata replacement | high | mitigate | One authority CAS validates exact expectation and immutable payload identity; spies deny every payload-lifecycle side effect. |
</threat_model>
