## Sampling Rate

- **After every task commit:** Run the focused participant, authority, lifecycle, migration, or packaging test file named by that task; use the quick run command when the task spans participant and evidence behavior.
- **After every plan wave:** Run all storage/lifecycle/migration tests affected by the wave plus Ruff on changed files.
- **Before `$gsd-verify-work`:** Full suite, clean-wheel import/round trip, optional-extra installation, and obsolete-mechanics negative audit must be green.
- **Max feedback latency:** 30 seconds for focused task feedback.
