**Opaque object transport observations are now signed against immutable payload identity in the sole verification transition, while metadata changes remain one authority-only CAS.**

## Accomplishments

- Added strict, bounded, domain-separated HMAC transport evidence that binds store, key, generation, locator, canonical SHA-256, byte size, opaque ETag, and optional version.
- Captured mocked-S3 object evidence after independent canonical snapshot verification and carried it through one `record_verification()` transition into promoted memory entries.
- Replaced catalog and user-metadata payload-lifecycle detours with one conditional authority transaction that preserves payload identity and byte-identical evidence.
- Corrected a superseded direct-read expectation so metadata-only updates prove the same immutable identity and zero payload lifecycle activity.

## Decisions Made

- A matching ETag never authenticates payload content; only canonical SHA-256 and size can do that.
- Metadata changes neither regenerate payload generations nor rebind transport evidence.
- SQLite and PostgreSQL implement the same narrow CAS to remain valid lifecycle authorities after the protocol extension; their current schema stores no new transport-evidence column.
