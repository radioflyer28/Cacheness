<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller data to filesystem blob backend | Untrusted user data is serialized to bytes and written to cache-controlled filesystem paths. |
| multiple local processes to same namespace directory | Independent writers can target the same final blob path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-01 | Tampering | FilesystemBlobBackend.write_blob | mitigate | Use race-free unique temp creation and atomic os.replace per D-01 through D-03. |
| T-30-01-D | Denial of service | temp cleanup | mitigate | Exception path unlinks only the unique temp file and leaves committed blobs available. |
| T-30-01-R | Repudiation | test evidence | mitigate | Test spies on tempfile.mkstemp and verifies final readable content per D-04 and D-26. |
</threat_model>
