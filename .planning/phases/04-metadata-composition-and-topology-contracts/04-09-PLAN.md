<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller catalog mapping/schema → signed descriptor | Untrusted structural catalog input must be bounded and validated before storage mutation. |
| StoreTopology payload participant → guarded handler I/O | An injected or registered object must supply the exact structural primitive and cannot redirect outside its validated root. |
| Payload primitive → lifecycle authority | The primitive stores bytes; only the existing authority may authorize visibility, recovery, or cleanup. |
