<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Store files → SQLite initialization | Existing DB identity/schema may be obsolete, corrupt, incomplete, or substituted. |
| Query AST/cursor → authority SQL | Caller-controlled fields/operators/values and cursor bytes reach a transactional authority. |
| Canonical descriptor → public result | Authenticated descriptor state is the only query source; scan remains complete. |

## STRIDE Threat Register — ASVS Level 1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-13 | Tampering | SQLite canonical descriptor | high | mitigate | Application/user version validation, one promotion transaction, signed descriptor verification, rollback faults. |
| T-04-14 | Tampering | query evaluator | high | mitigate | Finite operators/fields and pre-dispatch type validation over authenticated descriptors. |
| T-04-15 | Spoofing | opaque cursor | high | mitigate | HMAC plus format/store/schema/query/revision/identity binding. |
| T-04-16 | Denial of service | paging/membership | medium | mitigate | Predicate/item/page caps and keyset paging. |
| T-04-17 | Repudiation | retryable progress outcomes | low | accept | Typed context and original cause make retry diagnosis adequate for local library scope. |

Package legitimacy: not applicable; SQLite and crypto primitives are existing stdlib/project facilities.
