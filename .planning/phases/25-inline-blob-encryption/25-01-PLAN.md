<objective>
Add encryption support to the inline blob write and read paths in `_inline_blob_mixin.py`.

Purpose: Currently `_try_direct_inline()` stores plaintext bytes in `blob_data` and `_read_inline_blob()` has no decryption logic, meaning inline blobs bypass encryption entirely. This plan closes both gaps so inline blobs have the same encryption-at-rest guarantees as file-backed blobs.

Output: Modified `_inline_blob_mixin.py` with encryption on write (D-01, D-05) and decryption on read (D-02).
</objective>

```python
encryption_meta: dict[str, str] = {}
```

```python
return {
```

```python
# Decrypt inline blob if encryption metadata is present (D-02)
enc_algo = metadata.get("encryption_algorithm")
if enc_algo:
    if (
        not hasattr(self, "_blob_store")
        or self._blob_store is None
        or self._blob_store._encryption_key is None
    ):
        logger.warning(
            "Encrypted inline blob for %s but no encryption key configured",
            data_type,
        )
        return None
    from .encryption import decrypt_blob

    blob_bytes = decrypt_blob(
        blob_bytes, self._blob_store._encryption_key, iv
    )
```

This replaces `blob_bytes` with plaintext BEFORE the fast path (`handler.get_bytes(blob_bytes, metadata)`) and slow path (`tmp.write(blob_bytes)`) — both paths receive clean plaintext, matching D-02.

The guard clause pattern mirrors `_read_blob()` in blob_store.py: when encryption metadata is present but no key is configured, log a warning and return None (same behavior as file-backed encrypted blobs).

Key details:
- `metadata` parameter already contains `encryption_algorithm` and `encryption_iv` when the entry was encrypted (passed down from the caller)
- `blob_bytes` is reassigned in-place so all downstream code (fast path + slow path) uses plaintext
- When no `encryption_algorithm` is in metadata, the decryption block is skipped entirely (backward compatible)
- The `from .encryption import decrypt_blob` import is inside the conditional (lazy import, matches existing pattern)
