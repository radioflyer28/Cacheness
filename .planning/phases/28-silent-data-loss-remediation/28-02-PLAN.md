- `WriteIntentJournal.__init__()` receives `cache_dir` but only stores
  `cache_dir / ".intents"`.
- `cleanup_stale_intents()` resolves `Path(blob_path)` against CWD.
- Cleanup does not consult metadata before deleting a stale-intent blob.
- `UnifiedCache.__init__()` runs `_cleanup_stale_intents()` only when
  `cleanup_on_init` is true; storage mode sets it false.

Required API addition:
```python
def cleanup_stale_intents(
    self,
    entry_exists: Optional[Callable[[str], bool]] = None,
) -> int:
    ...
```
