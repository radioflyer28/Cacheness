## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| constructor cleanup -> public cleanup | Initialization invokes cleanup behavior before the user performs explicit operations. |
| public cleanup -> hooks | User-provided hook code is called but must not crash cleanup. |
| public cleanup -> blob filesystem | Metadata-derived paths are resolved and deleted. |

| T-29-02-02 | Denial of Service | init cleanup lock use | mitigate | Confirm initialization order and lock state before changing `_cleanup_expired` per D-09. |
