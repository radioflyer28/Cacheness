<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| source manifests/payloads -> candidate | Authenticated canonical entries cross into immutable external candidate effects. |
| verified receipt -> authority transaction | Only corroborated whole-candidate evidence may request canonical activation. |
| activated canonical state -> projection rebuild | Derived work occurs after publication and cannot revoke or redefine it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-21 | Tampering | source revision/candidate | high | mitigate | Revalidate identity/revision before every mutation and exact manifests/digests/counts before receipt issuance. |
| T-07-22 | Tampering | whole-store activation | critical | mitigate | Authority accepts only complete verified receipt and switches all canonical selection in one authority transaction with fault rollback tests. |
| T-07-23 | Repudiation | interruption/uncertain commit | high | mitigate | Domain-authenticated step receipts plus authority-state classification at every deterministic fault boundary. |
| T-07-24 | Elevation of Privilege | derived projection | high | mitigate | Invoke projection rebuild only post-activation and assert it cannot authorize membership, cleanup, rollback, or activation. |
</threat_model>
