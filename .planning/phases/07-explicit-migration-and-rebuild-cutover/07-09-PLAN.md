## Trust Boundaries

| Boundary | Description |
|---|---|
| exclusion plan/confirmation -> rebuild set | Operator-supplied omissions can destroy destination completeness or repudiation evidence. |
| authenticated source snapshot -> registered handler | Trusted application payload may execute unsafe serializers and must not run before authenticity/integrity authorization. |
| rebuilt candidate -> destination acceptance | Partial/unexplained data must never be adopted as complete canonical destination. |
